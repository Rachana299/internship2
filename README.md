# Hospital Appointment & Patient Management System

A runnable MERN application implementing the uploaded project specification: Patient, Doctor, and Administrator roles; JWT/RBAC; appointments with conflict prevention; medical reports; prescriptions with PDF generation; departments; dashboards; search/filtering; notifications; payments; and basic analytics.

## Requirements
- Node.js 18+
- MongoDB 6+ running locally (or a MongoDB Atlas URI)
- VS Code

## Run in VS Code

### 1. Backend
```bash
cd backend
npm install
copy .env.example .env   # Windows CMD
# or: cp .env.example .env
npm run seed
npm run dev
```
Backend: http://localhost:5000

### 2. Frontend
Open another VS Code terminal:
```bash
cd frontend
npm install
npm run dev
```
Frontend: http://localhost:5173

### Demo accounts
- Admin: `admin@hospital.com` / `Admin@123`
- Doctor: `doctor@hospital.com` / `Doctor@123`
- Patient: `patient@hospital.com` / `Patient@123`

## Notes
- Uploaded medical reports are stored in `backend/uploads` for easy local development. The API is structured so Cloudinary can be added later.
- Email notifications are optional. Add SMTP values to `.env` to enable real email delivery; otherwise notifications are still saved in MongoDB and shown in the UI.
- Prescription PDFs are generated by PDFKit and served by the backend.
